# StudyFlow

**StudyFlow — «Учись спокойно. Успевай больше.»**

MVP для хакатона: учебный планировщик, который помогает определить приоритеты, распределить нагрузку и видеть прогресс.

## Возможности
- Дашборд и Smart Priority.
- Добавление, редактирование, удаление и завершение задач.
- Поиск и фильтрация.
- Календарь дедлайнов.
- Автоматический план на 7 дней.
- Аналитика прогресса.
- Тёмная тема.
- localStorage.
- Демо-данные.
- Адаптивный интерфейс.

## Запуск
npm не нужен. Распакуй архив и открой `index.html` в браузере.

## GitHub Pages
Загрузи файлы в репозиторий → **Settings → Pages → Deploy from a branch → main → /root**.

## Для презентации
1. Ввести несколько задач с разными дедлайнами.
2. Показать Smart Priority.
3. Открыть План обучения.
4. Показать календарь и аналитику.

Smart-часть реализована локальным алгоритмом, поэтому не стоит утверждать, что продукт использует ChatGPT или другую внешнюю AI-модель.
